# Sinomart Landing Page

## SEO and deployment checklist (manual)

- Configure and keep the production custom domain as `https://sinomart.ng` on your hosting platform.
- Ensure HTTP redirects to HTTPS and the canonical host (`sinomart.ng` or `www` strategy) are enforced.
- Verify `https://sinomart.ng` in Google Search Console and Bing Webmaster Tools.
- Submit `https://sinomart.ng/sitemap.xml` in webmaster tools.
- Keep robots crawling enabled unless the site is intentionally private/staging.
